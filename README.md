# shearcsv

Shear lightweight csv statistics from stdin samples.

**Site:** https://theworker02.github.io/shearcsv/

## Install / run

```bash
git clone https://github.com/theworker02/shearcsv.git
cd shearcsv
node src/cli.js
node --test
```
